# 切粉検出・自律清掃システム（SO-101 × YOLO-seg × MuJoCo）

Physical AI 応用編1 最終課題。加工後の作業台に残った切粉を、俯瞰カメラ画像から **YOLOセグメンテーション** で検出し、SO-101 アームに取り付けたブラシで右側の回収トレー（切粉シュート）へ掃き寄せる自律清掃を、物理シミュレータ MuJoCo 上で実装しました。

- デモ動画：（YouTube の URL を記入）
- 実行環境：Google Colaboratory（T4 GPU）

## 背景と目的
機械加工の現場では、加工後のテーブルに残る切粉の清掃が、段取り・取り出し・検査などと並んで人手作業として残っています。本課題では、この清掃作業を「AIによる認識」と「ロボットによる実行」で自動化できるかを、シミュレーション上で検証しました。

## システム構成
```
俯瞰カメラ画像 ──▶ YOLO-seg（切粉マスク） ──▶ 画素→台上座標 ──▶ ストローク計画
     ▲                                                              │
     │                                                              ▼
MuJoCo（SO-101 + ブラシ + 切粉） ◀── 関節指令 ◀── 逆運動学（DLS） ◀─┘
```
1. **検出**：俯瞰カメラの画像を YOLO-seg（1クラス: chip）で推論し、切粉ごとのマスクを得る
2. **座標変換**：マスク重心を通る視線と台面の交点を計算し、台上の座標（m）に変換
3. **計画**：台上の切粉を距離でクラスタリングし、最も大きな塊の奥側から台の右端へ向かう直線ストロークを作成
4. **実行**：接近 → 降下 → 直線で掃く → 上昇 → 待機姿勢。各制御周期でブラシ先端の位置・姿勢を逆運動学で解く
5. **再検出**：台上に切粉が残っていれば 1 に戻る。なくなれば清掃完了

これを「加工完了（切粉が落ちる）→ 清掃」のサイクルとして繰り返します。

## 工夫した点
- **アノテーション不要の学習データ**：シミュレーションのセグメンテーション描画から正解マスクを自動生成。照明・色味・切粉の配置・アームの映り込みをランダム化して、清掃中の画像にも頑健にした
- **外部IKライブラリ不要の逆運動学**：MuJoCo のヤコビアンを使った減衰最小二乗法で、ブラシを鉛直下向き・幅方向を掃く向きに直交させたまま直線移動
- **幅6cmの平ブラシ＋シュートへの払い落とし**：工作機械で一般的な「テーブル側面のシュートへ払い落とす」構造を模擬し、回収を映像で一目で確認できるようにした
- **空振り対策**：同じ位置へのストロークが続いたら左右にずらす
- **評価の自動化**：検出結果（台上の残数）と、シミュレーション真値の回収率を毎ストローク記録

## 使い方（Colab）
`notebooks/chip_cleaning_demo.ipynb` を Colab で開き、ランタイムを T4 GPU にして上から順に実行してください。

| 手順 | コマンド | 目安時間（T4） |
|---|---|---|
| モデル取得 | `python src/download_assets.py` | 数秒 |
| 動作確認 | `python run_demo.py --detector gt --max-cycles 1 --scale 0.5` | 1〜2分 |
| データ生成 | `python generate_dataset.py --n-train 400 --n-val 100` | 数分 |
| 学習 | `python train_yolo.py --epochs 50` | 20〜30分 |
| デモ | `python run_demo.py --detector yolo` | 数分 |

出力：`outputs/demo_yolo.mp4`（等速、75〜170秒）と `outputs/demo_yolo_log.json`

## ファイル構成
```
├── config.yaml            # シーン・ブラシ・カメラ・計画・動作のパラメータ
├── generate_dataset.py    # 合成データ生成
├── train_yolo.py          # YOLO-seg 学習・評価
├── run_demo.py            # 清掃デモ・動画出力
├── notebooks/chip_cleaning_demo.ipynb
└── src/
    ├── download_assets.py # SO-101 モデル取得
    ├── scene.py           # シーン構築（MjSpec）・切粉の配置
    ├── dataset.py         # 合成データ・ラベル生成
    ├── detector.py        # YOLO 推論・真値検出・座標変換
    ├── planner.py         # クラスタリング・ストローク計画
    ├── ik.py              # 逆運動学（DLS）
    ├── controller.py      # 清掃ループ
    └── video.py           # 動画合成
```
